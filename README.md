# 날씨 정보 챗봇

Streamlit + LangChain 기반의 기상청 초단기실황 챗봇입니다.

## 실행

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

프로젝트 루트의 `.env`에 `.env.example`을 참고해 다음 값을 설정하세요. 기존 `.env`가 있다면 필요한 항목만 추가합니다.

```dotenv
OPENAI_API_KEY=발급받은_OpenAI_키
OPENAI_MODEL=gpt-6-astra
KMA_API_KEY=발급받은_기상청_API허브_키
```

`OPENAI_MODEL`은 사용할 수 있는 OpenAI 모델명으로 변경할 수 있습니다.

## 기상청 인증 설정

1. [기상청 API허브](https://apihub.kma.go.kr/)에서 인증키를 발급합니다.
2. 단기예보 → 초단기실황(`getUltraSrtNcst`)의 활용신청 및 사용 권한을 확인합니다.
3. `.env`에 `KMA_API_KEY`를 설정한 뒤 앱을 재시작합니다.

이 프로젝트는 API허브의 `authKey` 인증을 사용합니다. 공공데이터포털(data.go.kr)의 `serviceKey`를 입력하면 인증되지 않습니다. 키가 없으면 요청을 보내지 않고 설정 방법을 안내합니다. 401/403 인증 오류, 호출 한도, 타임아웃, 비정상 응답은 별도로 처리합니다.

## 동작

- 화면에서 기본 도시를 선택하거나 대화에서 지원 도시를 지정합니다. 각 시청 소재지의 대표 격자를 사용하며 상세 주소 검색은 지원하지 않습니다.
- 한국 시간 기준 매시 자료의 제공 지연 40분을 고려합니다. 최신 자료가 아직 없으면 한 시간 전 자료를 한 번 더 조회합니다.
- 성공한 조회는 지역·인증키·발표 시각별로 최대 5분간 캐시합니다. 오류는 캐시하지 않습니다.
- 기온·습도·강수·풍속과 관측 시각만 모델에 전달해 입력량을 줄입니다. 미래 예보·하늘 상태·미세먼지는 제공하지 않습니다.
- 에이전트를 재사용하고 답변을 스트리밍합니다. 화면에는 전체 대화를 유지하며 모델에는 최근 최대 10개 대화 턴, 약 16,000자 이내의 문맥을 전달합니다.
- 실패한 답변은 대화에 저장하지 않으며 다시 시도하거나 대화를 초기화할 수 있습니다.

## 검증

```bash
.venv/bin/python -m unittest discover -s tests -v
```

자동 검증은 모의 API 응답을 사용하므로 실제 인증키나 모델 호출 비용이 필요하지 않습니다. 실제 기상청 인증 및 관측값 확인에는 유효한 `KMA_API_KEY`가 필요합니다.
